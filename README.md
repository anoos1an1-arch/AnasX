# ذادريم — THE DREAM SPACE

نسخة GitHub Pages فقط.

## إضافة رابط جديد
افتح `links.json` وأضف عنصراً بهذا الشكل:

```json
{
  "id": "unique-id",
  "title": "اسم الرابط",
  "description": "وصف اختياري",
  "url": "https://example.com",
  "icon": "globe"
}
```

- `title` = اسم الرابط
- `url` = الرابط
- `icon` = اسم أيقونة من Lucide مثل `globe`, `youtube`, `instagram`, `github`, `link`, `book-open`
- `description` اختياري ويمكن حذفه.

لأن الموقع مستضاف على GitHub Pages، تعديل الروابط يتم من المستودع نفسه، وليس من صفحة عامة للزوار.
